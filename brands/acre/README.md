# Acre Security — logo files

Cut from *Acre Security Technologies Brand Guidelines, Phase One v1 (2025)*, p. 47 ("Suitable logo / color combinations"). Transparent background; for use on light/white backgrounds only.

| File | Use |
|---|---|
| `acre-logo-horizontal-plum.png` | Default in proposals — symbol + wordmark, one line |
| `acre-logo-stacked-plum.png` | Square-ish spaces |
| `acre-wordmark-plum.png` | Text-only lockup |
| `acre-security-wordmark-plum.png` | "acre Security" sub-brand (Acre access control / intrusion lines) |

Rules (from the guidelines):
- Minimum size on screen: logo 50 px tall, wordmark 25 px tall. Keep clear space of 1× the wordmark height on every side.
- Light backgrounds: plum versions (these files). Dark backgrounds or dark photos: white/keyline versions — not in this folder yet.
- Don't recolor, stretch, or place over busy photography. Phase Two logos are "not yet available for use".
- Acre's lifestyle/product photos in the guidelines are inspiration only and **not authorized for distribution** — don't use them.
- Colors: Legacy Plum `#2B0030`, Acre Primary `#543458`, Security `#5D3883`, Legacy Gray `#D0D0D0`, Cloud White `#F8F8F8`.
- Brand contact: kaseythomas@acresecurity.com
