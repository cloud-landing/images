# images
Public image hosting for FlyLock Security Solutions Seattle — logos, badges, watermarks and manufacturer branding used in proposals, emails and documents.

**Public repo: never add customer site photos, floor plans, System Surveyor maps, or anything showing a customer's building or security layout.** Those go straight into the Portal proposal (uploaded per proposal), not here.

## Layout
- Root files — existing FlyLock logos, watermark, ASIS/ESA badges, icons. Left in place because they may be linked from signatures and documents; don't move or rename them.
- `brands/<manufacturer>/` — manufacturer logos and approved product images, one folder per brand, each with a README listing the files, the source and the brand's usage rules.

## Linking
Raw URL pattern: `https://raw.githubusercontent.com/cloud-landing/images/main/<path>` (spaces as `%20`).
